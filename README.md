Bước 1: Trong Power BI Desktop, chọn File → Save As → Power BI Project (.pbip).
Bước 2: Chuẩn bị toàn bộ project, ví dụ:
Purchasing_Dashboard/
│
├── Purchasing_Dashboard.pbip
│
├── Purchasing_Dashboard.Report/
│   ├── definition.pbir
│   └── definition/
│       └── pages/
│
└── Purchasing_Dashboard.SemanticModel/
    ├── definition.pbism
    └── definition/
        ├── model.tmdl
        └── tables
Bước 3: Nén thư mục thành ZIP để chuẩn bị chia sẻ, hoặc tải các file định nghĩa lên ChatGPT. Khả năng nhận ZIP trực tiếp tùy giao diện; nếu không nhận, có thể gửi các file văn bản bên trong.

Bước 4: Gửi thêm dữ liệu Excel/CSV mẫu hoặc kết nối nguồn dữ liệu được hỗ trợ. Lưu ý: PBIP thường chứa cấu trúc model, không nhất thiết chứa dữ liệu thực tế
